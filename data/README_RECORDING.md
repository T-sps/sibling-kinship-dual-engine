# 国标数据录入指引（最重要的人工任务）

> GB/T 43641-2024 标准为**扫描影像版**（无文字层），无法复制粘贴，必须人工录入。
> 录入错误会直接污染所有鉴定结果，故须**严格双人交叉核对**。

## 需录入的 4 份资源（对应本目录 4 个 JSON）
1. `locus_registry.json` —— 19 个必检基因座（+可选）；Amelogenin 标 `type="SEX"` 不参与计算
2. `allele_freqs.json` —— 中国汉族人群等位基因频率
3. `thresholds_ibs.json` —— CIBS 判定阈值（按有效基因座数 n）
4. `thresholds_fsi.json` —— Log10(CFSI) 判定阈值（按 n）

## 录入流程（双人交叉核对）
1. 两人**独立**读国标附录，各自录入同一份表（A 录入、B 录入）。
2. 逐数值比对两份结果，不一致则回查原标准页，以国标原文为准。
3. 每个数值在 `source_clause` 字段标注 `GB/T 43641-2024 附录X 表Y 第Z页`。
4. 核对一致的条目置 `verified=true`。
5. 频率表录入后运行校验：每个基因座频率和应 ≈ 1.0。
6. 所有变更经 git 提交，commit message 写明「录入 附录X 表Y」。

## 录入前必须与导师拍板的规则（见根 README 风险清单）
- 稀有/表外等位基因频率处理方法
- 缺失基因座处理（跳过并减 n？）
- 两引擎结论冲突的仲裁规则
- 突变是否纳入 FSI 计算

> 这些规则不定，FSI 引擎就无法正确实现——务必在录入阶段一并确认。
